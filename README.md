# Gaussian processes 

This repository contains some code for Gaussian Process (GP) metamodeling on (smooth) continuous functions. It uses the very efficient GP modeling library [GPyTorch](https://gpytorch.ai/), itself based on [PyTorch](https://docs.pytorch.org/docs/2.14/index.html).

## Technical references 
- As mentioned at the beginning, the [GPyTorch](https://gpytorch.ai/) documentations page offers a lot of tutorials and examples of GP usage with more advanced examples
- The [PyTorch](https://docs.pytorch.org/docs/main/) documentation can also be handy as (again, as mentioned in the beginning) GPyTorch relies itself on PyTorch. 

## Some references for benchmark models 
- The [Virtual Library of Simulation Experiments] (Sonja Surjanovic & Derek Bingham, Simon Fraser University) is a useful ressource that regroups benchmark functions for various aspects of simulation (optimisation, uncertainty quantification, functional data, ...).
